Vitrine

Drop-in web components to display code, Markdown and JSON beautifully — on any website, with zero framework.

Early development — components are being built. APIs may change before v1.0.

View on GitHub Open the demo

One script tag

<script src="https://cdn.jsdelivr.net/gh/ecrou-exact/vitrine@1/dist/vitrine.min.js"></script>

<vt-code language="python" line-numbers>
def hello(name):
    return f"Hello {name}"
</vt-code>

<vt-code>

Syntax highlighting, line numbers, highlighted lines, search, copy, download and diff.

<vt-markdown>

Sanitized GFM rendering with Preview / Source / Split tabs, table of contents and anchors.

<vt-json>

Pretty-printed or collapsible tree view, search, copy value and JSON path.

Works everywhere

Plain HTML, PHP, WordPress, Django, Vue, React, Svelte, Angular. No Node.js for consumers.

Secure by default

Sanitized output, no eval, CSP-friendly, Trusted Types support.

Themable

Shadow DOM isolation, CSS custom properties and ::part(), light and dark themes.
