Display anything, anywhere_

Web components that show code, Markdown, JSON, tables, diffs, terminals, file trees and HTTP calls on any site. One script tag, no framework, safe with content you did not write.

Nine elements, view or edit

Each element works as a plain block in its simple variant. Add variant="full" for the toolbar, search and tabs, switch features on one attribute at a time, and add mode="edit" to let people change the content.

Built to be dropped into other people's pages

No framework, no build step
Standard custom elements. They work in plain HTML, PHP, WordPress, Django, Vue, React, Svelte and Angular.
Secure by default
Sanitized Markdown, no eval, size and depth limits. Works under a strict CSP with Trusted Types, like this site.
Themable in one line
Five built-in themes, CSS variables on any ancestor, ::part() selectors and custom themes.
Accessible
Keyboard tabs and trees, labelled controls, screen reader announcements and WCAG AA contrast in every theme.

Quick start

Pick the way your site loads scripts. Consumers never need Node.js.
