Examples

Each example shows the live component next to the exact markup that renders it. Copy the markup, change one attribute, and you get the same result on your site.

<vt-code>

Simple block

The default variant: highlighted code, nothing else. Indentation inside the element is removed.

Line numbers, first line and emphasized lines

highlight-lines uses the displayed numbers, so it follows start-line.

Full variant

Header with title and language, search, wrap toggle, download and copy. Open the search and press Enter to move between matches.

Full variant, minus some features

Individual attributes always win over the variant preset.

Simple variant with a copy button

Without a header, actions float in the corner and appear on hover or focus.

Diff

Lines starting with + and - are marked as added and removed. The copy button copies the diff as written.

Collapsible and wrapped

collapsible="4" shows four lines and a button; wrap soft-wraps long lines.

Any language, loaded on demand

Common languages are bundled; the other 180 are fetched only when used. language="auto" detects the language.

Theme and custom properties

theme picks a built-in theme; CSS variables override any token. This page sets .brand-example { --vt-accent: #7c9cff; --vt-accent-fg: #7c9cff; --vt-radius: 4px; }.

Interface language

English and French ship with the library; register other languages with Vitrine.registerLocale().

<vt-markdown>

Simple rendering

GitHub Flavored Markdown with highlighted code blocks. The text uses the page font.

Full variant

Preview, source and split tabs (use the arrow keys), table of contents, heading anchors, search and copy.

Chosen tabs, source first

tabs picks which tabs exist and in which order; default-tab picks the first one shown.

Raw HTML

By default raw HTML is shown as text. With allow-html it is rendered, but sanitized: the script and the event handler below are removed.

Image policy

images="block" replaces images with their alt text, so content cannot track readers with remote pixels.

Loaded from a file

src loads same-origin files by default. Relative links and images resolve against the file.

<vt-json>

Pretty printed

The simple variant formats and highlights JSON. Numbers are shown exactly as written.

Tree view

Click a row to see its JSONPath and copy it. Arrow keys move through the tree; Right and Left open and close nodes.

Raw view, sorted, indented by 4

view, sort-keys and indent shape the raw view.

Invalid JSON

The error says what is wrong and where, and the line is highlighted. on-invalid="raw" shows the text with a notice instead.

From JavaScript

For data you did not write, set the content property (or data on <vt-json>). It is never parsed as HTML.

Vitrine.render()

Creates the element, sets its attributes and content, and puts it in the target.

A JavaScript value, with events

The data property serializes any value. Every component dispatches vt-* events.
